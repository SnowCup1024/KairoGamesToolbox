# 开罗游戏工具箱

Windows x64 游戏管理器与模组控制平台。当前版本 **v1.0 Beta 5**（内部版本 1.0.5），支持简体中文、繁体中文、英文、日文，以及跟随系统、浅色和深色主题。

最新变更见 [更新日志](CHANGELOG.md)。

## 功能

- 管理 Steam 与非 Steam 开罗游戏，内置 63 款游戏目录，支持中文、英文、拼音及首字母搜索。
- 查看游戏目录、存档目录及可用的 Steam 游玩记录；封面从用户缓存、Steam 来源加载，失败时显示占位图。
- 安装、更新、删除游戏专用模组，并通过启动器实时设置开关与倍率。

支持的模组及各游戏说明见 [模组目录](Mods/README.md)。

反加按实际扣除量计算：实际消费 10，50x 使余额相对消费前净增加 500；0x 为“不消耗”，返还实际消费、余额不变。关闭开关恢复正常消耗。正常收入不放大，资金不足、解锁及游戏上限仍由游戏判断。

## 使用

1. 启动工具箱。Steam 路径会自动检测，也可在设置中填写并验证。
2. 添加非 Steam 游戏时，选择直接包含 `KairoGames.exe` 的目录；依据 `KairoGames_Data/app.info` 识别游戏，不按文件夹名称猜测。
3. 在游戏详情的「游戏目录与模组状态」中安装模组。首次安装需要联网下载并校验共享运行组件；游戏指纹不匹配时拒绝安装。
4. 正常启动游戏，打开「模组控制」设置开关和倍率。无需热键或先进入存档；插件会等待游戏对象就绪。
5. 退出游戏后可更新或删除模组。更新和删除仅处理已识别且指纹匹配的受管理文件，保留未知文件和游戏原文件。

所有修改默认关闭。卸载模组不会撤销已经保存的金钱、道具等变化，请使用备份存档测试。启动器关闭不会强制关闭游戏，也不会撤销游戏中正在生效的设置；新启动器首次连接会发送全关闭、1x 的设置。

模组控制页可见时每 15 秒检查连接；断线后控件变灰并保留显示状态，重连时恢复本次启动器进程中按游戏目录记忆的设置。日志支持复制、清空显示及暂停刷新，最多保留 500 行；清空显示不删除磁盘日志。正常模式翻译资源结果，开发模式保留原文。

启动器保持单实例：发现旧版本时会询问是否关闭旧版并启动新版；选择“否”则打开旧版。

## 数据与目录

用户数据保存在 `%LocalAppData%\KairoGamesToolbox`：

| 路径 | 内容 |
| --- | --- |
| `settings.json` | 语言、主题、Steam 路径及由 Windows DPAPI 加密的 API Key |
| `non-steam-games.json` | 手动添加的游戏目录 |
| `Covers` | 按 AppID 缓存的封面 |
| `Mods/Runtime` | 经 SHA256 校验的共享运行组件 |

Steam API Key 为可选项，仅用于拥有状态、游玩时长与最近游玩时间；缺少它不影响启动。再次编辑已保存的 Key 时清空重填，未保存离开会恢复掩码。

| 仓库路径 | 职责 |
| --- | --- |
| `Windows/Core` | 独立于 WinUI 的模型、识别、安装事务、通信、本地化与缓存 |
| `Windows/Launcher/Source` | WinUI 界面和页面生命周期 |
| `Windows/Launcher/Data` | 游戏目录和应用图标 |
| `Windows/Test` | 启动器与核心逻辑的无头测试 |
| `Mods/Games` | 按游戏组织的源码、自有插件 DLL 和声明式定义 |
| `Mods/Shared` | 启动器与插件共用协议 |
| `Mods/Notices` | 上游许可声明 |
| `Mods/ControlTests` | 成品模组的结算、协议及安装组合测试 |
| `Scripts` | 构建、校验和发布脚本 |
| `.Build` | 忽略的构建、下载、导出和临时记录，不提交 |
| `.TestGames` | 可选的本地游戏测试副本，不提交 |

## 开发与分发

需要 Windows 和 `global.json` 指定的 .NET SDK。启动器与核心使用 .NET 8，游戏插件使用 .NET 6。普通启动器构建使用仓库内的自有插件 DLL，不需要商业游戏；重编插件才需要对应游戏的互操作程序集与匹配运行组件。

开发构建：

```powershell
dotnet build Windows/KairosoftGameToolbox.sln --configuration Debug
```

需要启动调试程序时，在仓库根目录执行：

```powershell
dotnet run --project Windows/Launcher/KairosoftGameToolbox.csproj --configuration Debug
```

按变更选择的测试、发布步骤及版本规则见 [贡献规范](CONTRIBUTING.md)，插件重编方法见 [模组技术说明](Mods/README.md)。

发布产物是自包含 .NET／WinUI 的单个 EXE，启用单文件压缩，未启用 IL 裁剪。游戏专用 DLL 随启动器内嵌；共享运行组件首次安装时从固定官方地址下载并校验，后续复用合法缓存。首次生成 IL2CPP 互操作文件可能需要额外下载和等待。
