# 更新历史

本文件随仓库提交，按版本维护产品变更摘要；根目录 [CHANGELOG.md](../CHANGELOG.md) 只保留最新版本。历史由当前仓库及所有可达提交中的 README、CHANGELOG、模组说明和开发记录交叉整理，下面标注可追溯提交；不把旧行为作为当前规范，也不补写无证据的功能。游戏专属细节只保留在 Mods 内。

## v1.0 Release（1.0.7）

2026-09-15。来源：[当前更新日志](../CHANGELOG.md)；首次正式发行。

- 已拥有未安装游戏显示下载入口，详情头部只保留封面、较大的游戏名与操作按钮。
- 未安装专用模组时隐藏控制页；卸载改为确认后执行，不再按同名进程拦截。
- 安装组合包避免重复压缩，更新跳过未变化文件的解压及备份，保留校验与回滚。
- 维护者确认现有两款内嵌模组实机测试正常，沿用已验证载荷。
- 增加长期更新历史，拆分贡献规范，注明 AI Agent 开发参与。

## v1.0 Beta 6（1.0.6）

来源：`7712bb2` 的 CHANGELOG 与提交；本地构建规范随后补充。

- 安装／更新不再根据通用游戏进程名阻止，失败显示原因和文件占用提示。
- 关于页显示内嵌的最新更新日志，正文具有四语言译文。
- 开发更新也生成 EXE 与 ZIP，同版本直接覆盖，与是否创建 GitHub 发行记录无关。

## v1.0 Beta 5（1.0.5）

来源：`476cbf7` 的 CHANGELOG；GitHub 预发行版。

- 模组统一三档倍率并补充零消耗标识，重编内嵌载荷；模组改用日期与哈希管理，兼容旧安装记录。
- 单实例增加旧版本切换确认；模组安装状态显示发布日期。
- 清除废弃探针、开发记录和一次性工具，正式命名同步，模组文档按游戏归位。
- 协作入口纳入版本管理；发布成功清理编译缓存，失败保留现场。
